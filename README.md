# EDA-Weather-Dataset-Using-Python
This project focuses on performing Exploratory Data Analysis (EDA) on a real-world weather dataset using Python and popular data analysis libraries such as Pandas, NumPy, Matplotlib, and Seaborn

# The main objective of this project is to explore, analyze, and extract meaningful insights from historical weather data by applying various data analysis techniques.

# Key Objectives

Understand the structure and characteristics of the weather dataset
Perform data cleaning and inspection
Analyze weather conditions, wind speed, visibility, humidity, and temperature
Identify patterns, trends, and relationships in the data
Answer specific business-type analytical questions using Python

# Tools and Technologies Used

Python
Pandas – Data manipulation and analysis
NumPy – Numerical operations
Matplotlib – Data visualization
Seaborn – Advanced visualizations
Jupyter Notebook – Interactive analysis

# Analysis Performed

The project includes analysis such as:
Finding unique weather conditions
Analyzing wind speed variations
Counting specific weather types (e.g., Clear weather)
Examining visibility, humidity, and temperature distributions
Dataset structure analysis (shape, columns, data types)
Statistical summaries and value counts

# Key Skills Demonstrated

Exploratory Data Analysis (EDA)
Data Cleaning and Inspection
Data Visualization
Analytical Thinking
Python for Data Analysis

# Dataset

The dataset contains various weather attributes including:
Temperature
Humidity
Wind Speed
Visibility
Weather Condition
